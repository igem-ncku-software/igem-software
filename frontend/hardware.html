Self-check

Checks the reader before you calibrate or measure: stray light, dark stability, LED response, and peak signal. Takes a few seconds. Nothing is saved.

  1. Insert a cuvette of buffer only. No cells or AHL, so the reading reflects the reader, not a sample.
  2. Close the lid. Room light reaching the sensor would show up as stray light.
  3. Run the self-check. The reader takes a dark reading, one with the LED on, and a second dark reading.

Research use only. This device reads relative fluorescence only and is not intended for diagnostic use.
